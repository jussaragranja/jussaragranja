## Por que SDD aqui?

Um README de perfil é um **produto**: tem público, proposta de valor e critérios de sucesso.
Editar direto no arquivo (vibe editing) leva a "lista de tecnologias sem narrativa".
Com SDD, você **escreve a especificação primeiro** (objetivo, público, requisitos, critérios de aceite) e só então implementa — garantindo que cada seção sirva a um propósito.
